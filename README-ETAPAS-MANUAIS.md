# AgroFeira — etapas manuais pendentes

Os arquivos HTML e CSS das Atividades 04 e 05 foram montados. Antes de publicar, ainda é necessário completar as etapas que dependem do seu GitHub/Chrome:

1. Baixar do repositório da disciplina as sete imagens `acai.jpg`, `farinha.jpg`, `banana.jpg`, `pimenta.jpg`, `cacau.jpg`, `cupuacu-640.jpg` e `jambu.jpg` e colocá-las na raiz deste repositório, ao lado de `index.html`. A imagem `cupuacu.jpg` que já existia é menor e não substitui `cupuacu-640.jpg`.
2. Preencher em `comparativo.html` nome completo, matrícula, URLs, medições e análises com os valores obtidos no Chrome. Os valores não foram inventados.
3. Salvar oito capturas com os nomes já usados nos `src` do `comparativo.html` e colocá-las na raiz. Depois, substituir em cada `<img>` de `comparativo.html` os valores provisórios de `width` e `height` pelas dimensões reais da captura (o editor mostra essas medidas ao abrir o PNG).
4. Sincronizar/publicar pelo GitHub Codespaces.

Os botões de categoria e de adicionar são apenas elementos visuais nesta atividade; o roteiro não pede lógica de filtragem ou carrinho.
