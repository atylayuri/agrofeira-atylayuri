# AgroFeira 

## Páginas principais

- `catalogo.html`: catálogo autoral, com grade responsiva, menu, barra de categorias, cartão adaptável por container query, foco visível e tema escuro.
- `catalogo-bootstrap.html`: catálogo com Bootstrap, sete cartões, aviso de entrega e lista lateral de mais pedidos.
- `index.html`, `safra.html`, `cadastro-produtor.html` e `sobre.html`: páginas existentes integradas às folhas CSS em camadas.

## Folhas de estilo

- `camadas.css`: ordem das camadas CSS.
- `reset.css`, `tokens.css`, `base.css`, `componentes.css` e `utilitarios.css`: estilos do site autoral.
- `agrofeira-bootstrap.css`: mapeamento das variáveis do Bootstrap para os tokens do projeto.

## Observação

Os botões de categoria e “Adicionar” são visuais, conforme o escopo das atividades; não foi adicionada lógica de filtro ou carrinho.
