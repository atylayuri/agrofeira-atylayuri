O que eu aprendi

1. As três formas de JavaScript

Para um programa com vária linhas compartilhado entre várias páginas, a escolha ideal é o JavaScript externo, armazenado em um arquivo .js próprio e conectado ao HTML pelo atributo src. Essa abordagem permite um maior controle e flixibilidade do códgio além da forma que permiti a alteração e manutenção do código mais facilmente operavel.

2. Repetição e componentes React

No arquivo catalogo.html da AgroFeira,os cartões de produto que estruturam as mercadorias oferecidas se repetem várias vezes. O componente equivalente que substituiria essa repetição de código seria o componente Produto, cumprindo o mesmo papel de reaproveitamento que o Square teve no tabuleiro. é útil para otimizar a estrutura do site e evitar blocos de códigos longos e redundantes.

3. Props e estado no React

O componente Produto recebe o nome do item (como "Açaí", do catálogo) por meio de props, enquanto o texto do botão é gerenciado pelo estado rotulo — que alterna de "Adicionar" para "No carrinho" ao ser clicado. Como cada instância possui um estado isolado e independente, clicar em um produto não interfere nos outros. Assim, selecionar o Açaí e a Banana altera somente os seus respectivos botões, deixando a Farinha d'água com o rótulo inicial.

4. A decisão de estilo

Mantive a minha escolha inicial pelo uso do Bootstrap na AgroFeira, pois a produtividade e a padronização oferecidas pelos seus componentes prontos continuam sendo grandes vantagens para o projeto. Ainda assim, a experiência prática com um arquivo styles.css escrito à mão no CodeSandbox mostrou que o CSS autoral também é totalmente viável para estilizar os cartões de produtos. Para as próximas etapas do desenvolvimento, essa decisão apenas exigirá atenção redobrada para gerenciar possíveis conflitos entre o comportamento do framework e os componentes dinâmicos do React.
